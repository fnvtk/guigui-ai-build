## 乖乖AI能做什么

- **多个助手一起工作**：为不同任务设置不同助手，分别管理对话、性格和工作方式。
- **本地优先**：重要资料和对话保存在自己的设备上，减少不必要的外传。
- **清晰的确认流程**：涉及文件、命令或外部应用的操作，会先展示给你确认。
- **连接常用工具**：按需连接邮箱、日历、项目管理和其他工作工具。
- **电脑端协作**：助手可以在独立的工作环境中处理任务，并随时查看进展。

## 安装与使用

1. 下载上方的安装程序。
2. 双击安装程序，按照提示完成安装。
3. 打开乖乖AI，创建或选择一个助手。
4. 在设置中连接你正在使用的智能模型或工具。
5. 直接描述目标，涉及重要操作时按提示确认即可。

## 下载说明

- 视窗电脑：下载页面中的安装程序，适用于常见的六十四位电脑。
- 苹果电脑：请在版本页面选择对应芯片的安装文件。
- 如果浏览器提示文件较大，请等待下载完成后再运行安装程序。
- 首次启动时，系统可能会询问文件访问或网络权限，请根据实际需要选择。
