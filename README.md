## 乖乖AI能做什么

- **多个助手一起工作**：为不同任务设置不同助手，分别管理对话、性格和工作方式。
- **本地优先**：重要资料和对话保存在自己的设备上，减少不必要的外传。
- **清晰的确认流程**：涉及文件、命令或外部应用的操作，会先展示给你确认。
- **连接常用工具**：按需连接邮箱、日历、项目管理和其他工作工具。
- **电脑端协作**：助手可以在独立的工作环境中处理任务，并随时查看进展。

## 安装与使用

1. 下载上方的安装程序。
2. 双击安装程序，按照提示完成安装。
3. 打开乖乖AI，创建或选择一个助手。
4. 在设置中连接你正在使用的智能模型或工具。
5. 直接描述目标，涉及重要操作时按提示确认即可。

## 给普通用户的使用方法

你可以把乖乖AI当成一个随时可以叫到的工作伙伴：

1. 先告诉助手你想完成什么，不需要先学复杂设置。
2. 如果任务需要整理资料、写文案、分析文件或规划步骤，直接说出目标。
3. 助手准备执行重要操作时，会先把内容展示出来，由你确认。
4. 任务完成后，可以继续追问、修改或让另一个助手接着处理。

## 产品介绍文案

乖乖AI，把多个智能助手放进一个清晰、安心、容易上手的工作台。

它适合需要写作、整理、分析、计划和执行的人，也适合希望让多个助手分工合作的小团队。每个助手都有自己的工作方式，你可以让它们各自负责不同事情，也可以让它们围绕同一个目标一起推进。

少一点来回切换，多一点真正完成。打开乖乖AI，说清楚目标，剩下的事情一步一步完成。
