# 乖乖Ai 0.1.139 Windows 与 AI 配置更新说明

## 默认发布规则

桌面正式发布同时生成 Windows 与 macOS 两个平台的安装包。GitHub Release 工作流分别在 Windows/macOS runner 上构建后再汇总；本机 `pnpm package` 也按同一顺序执行两个平台构建。macOS 构建需要已配置签名身份，Windows 构建需要 Windows 构建环境。

## 本版内容

- 侧栏默认展开机器人分配的协作任务，并显示“协作任务（机器人已分配）”。
- 协作任务进行中时显示实时状态，打开左侧对话即可查看分配和处理过程。
- Windows x64 安装包使用与本版本源码相同的提交构建，避免 Windows 与 macOS 功能不一致。
- AI 设置只保留 SimpleAPI：直接输入 API Key 即可保存、验证和使用。
- 首页连接 AI 只显示 SimpleAPI，移除 OpenAI、Anthropic、xAI、OpenRouter 等多余入口和复杂说明。

## 安装

下载 `乖乖Ai-0.1.139-setup.exe`，运行安装程序并按提示完成安装。安装包会覆盖同版本旧安装，不需要重复安装多个副本。

## 验证

- 版本：`0.1.139`
- 平台：Windows x64
- 构建：GitHub Actions 的真实 Windows runner
- 检查：打包服务启动、浏览器资源、Windows CUA 组件和安装包目录完整性
- Windows 安装包未配置代码签名证书；首次运行时 Windows SmartScreen 可能显示“未知发布者”，请确认来源后选择继续。

## 已知说明

本次只发布一个最新 Windows 安装包。`latest.yml` 和 `.blockmap` 若随 GitHub Release 一并提供，仅用于自动更新元数据，不是额外安装程序。
