## 安装方法

1. 根据自己的电脑类型选择安装包。
2. 下载完成后双击安装包。
3. 按照系统提示完成安装。
4. 打开乖乖AI，创建或选择助手。
5. 在设置中连接需要使用的模型或工具。

## 使用方法

直接告诉助手你要完成的目标，例如整理资料、写文案、分析文件或安排计划。涉及文件修改、命令执行和外部操作时，请先查看内容，再确认执行。

## Linux版本

Linux版本需要在Linux六十四位构建机上完成打包和启动验证，目前暂未提供下载链接。
